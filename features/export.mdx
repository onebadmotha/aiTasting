At any point during or after your run, you can export your adventure from the toolbar at the top of the game screen. Two export formats are available — a structured JSON snapshot of your full game state, and a human-readable Markdown chronicle of everything that happened. Both download instantly to your device with a single click.

## Export JSON

Click the **Export JSON** button in the toolbar (yellow) to download a complete snapshot of your current game state.

The file is named using the pattern `rpg_state_<charactername>_<timestamp>.json` and contains the full `gameState` object with the following fields:

| Field | Contents |
|---|---|
| `character` | All 9 wizard fields plus current and max HP |
| `logs` | Array of every terminal message from the session |
| `tables` | Remaining pool entries for all 6 procedural tables |
| `inCombat` | Boolean — whether combat is currently active |
| `currentEnemy` | The name of the current enemy, if any |
| `gameOver` | Boolean — whether the run has ended |
| `ttsEnabled` | Whether TTS narration is switched on |
| `wizardStep` | The character-creation wizard step you reached |

Here is a short example of the exported structure:

```json
{
  "character": {
    "name": "Kael Duskbane",
    "class_name": "Shadow Rogue",
    "timeline": "The Age of Ashen Rust",
    "hp": 7,
    "maxHp": 10
  },
  "inCombat": true,
  "currentEnemy": "Shadow-Bound Rogue",
  "gameOver": false
}
```

## Export Story (Markdown Chronicle)

Click the **Export Story** button in the toolbar (pink) to download a formatted Markdown document that reads like a narrative account of your run.

The file is named `chronicle_<charactername>_<timestamp>.md` and contains:

- A **character sheet header** with your name, class, era, companion, and current survival status
- The **full action log** with all HTML tags stripped, presenting clean prose and die-roll text
- A **footer** crediting the Terminal 1d6 RPG engine

Here is an example of the exported Markdown structure:

```markdown
# Chronicle of Kael Duskbane
**Class:** Shadow Rogue  
**Era:** The Age of Ashen Rust  
**Companion:** Nixie (Shadow Cat)  
**Status:** Alive (HP: 7/10)

---

## The Log of Deeds & Die Rolls
...

---
*Generated by Terminal 1d6 RPG Engine.*
```

<Note>
  Exporting does not clear your save. You can export and continue playing from exactly the same point.
</Note>

<Tip>
  Export your adventure before clicking **Reset** — once you confirm a reset, your save is permanently erased and cannot be recovered. An export gives you a lasting record of your run.
</Tip>
